# Milestone 4: 実務化（1〜2か月）

## 重点

「モデルを学べる」状態から、「案件を切って設計できる」状態へ移る。

## 学ぶこと

- タスク選定: 分類で足りるか、検出が必要か、セグメンテーションまで要るか
- ベースライン設計
- 評価設計
- エラー分析設計
- アノテーション指示書作成
- 推論パイプライン化
- ONNX, TensorRT, 軽量化の入口
- 最低限の MLOps: 実験管理、データ版管理、前処理版管理、推論再現性

## 到達基準

少なくとも以下を説明できる状態を目指す。

- まず必要なのは分類ではなく検出
- 精度が出ない最大要因はモデルではなく位置ずれやラベル品質
- このデータでは全面 resize より patch 化が安全
- val が高すぎるので leakage を疑うべき
- OCR 前に deskew と射影補正を入れるべき
- 深度推定で resize するなら intrinsics 更新が必要

## 最終成果物

- 新規案件向けの要件確認チェックリスト
- タスク別ベースライン設計テンプレート
- 評価設計・エラー分析テンプレート
- アノテーション指示書テンプレート
- 再現可能な推論パイプラインの雛形
